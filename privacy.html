くーりーだー プライバシーポリシー

くーりーだー（以下「本アプリ」）は、作者が自分だけで使うための個人用アプリです。本アプリでの情報の扱いについて、次のとおり定めます。

1. 使う情報

本アプリは、利用者の許可を得たうえで、Google ドライブの次の情報を使います。

  • 決められたフォルダの中にある記事ファイルの名前、日付、種類
  • 記事ファイルの中身（アプリの中で表示するため）

2. 使う目的

  • 記事を一覧にして表示し、アプリの中で読めるようにするため
  • 利用者が選んで確認した記事を、ドライブのゴミ箱に移すため

これ以外の目的には使いません。ファイルを完全に削除したり、書きかえたり、ほかのファイルやフォルダを動かしたりすることはありません。

3. 情報の保存場所

ログインの情報と、表示のために読み込んだ記事は、利用者の端末の中だけで扱います。作者や第三者のサーバーに送ることはありません。

4. 第三者への提供

集めた情報を、第三者に売ったり、渡したり、広告に使ったりすることはありません。

5. Google API サービスのポリシーについて

本アプリが Google API から受け取った情報の利用と他のアプリへの移転は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。

6. 許可の取り消し

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」 から、いつでも本アプリへの許可を取り消せます。

7. 変更

このポリシーを変えるときは、このページを更新します。

Privacy Policy (English summary)

Kuu Reader is a personal app used only by its author. With the user's permission, it reads the names, dates, types and contents of article files in a specific Google Drive folder in order to list and display them, and moves files to the Drive trash only when the user selects and confirms. It does not permanently delete, modify or move any other files. Login data and article contents are handled only on the user's device and are never sent to the author or any third party. Data is never sold, shared or used for advertising.

Kuu Reader's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at https://myaccount.google.com/permissions.
